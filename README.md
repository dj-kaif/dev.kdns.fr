# dev.kdns.fr

A domain looking for something worth building.

dev.kdns.fr is an unused developer domain. Instead of letting it sit idle, this site invites developers with useful, interesting, or creative projects to reach out — approved projects may get a subdomain like `project.dev.kdns.fr`.


## Structure

```
dev-kdns-fr/
├── index.html    main landing page
├── legal.html    terms, privacy, credits
├── style.css     all styling and design tokens
├── script.js     year, card hover glow, mailto links
└── favicon.svg   site icon
```
